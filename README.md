## Selected Data Set
### NCHS - Leading Causes of Death: United States in data.gov
### URL: https://catalog.data.gov/dataset/nchs-leading-causes-of-death-united-states
### The Leading Causes if Death: United States dataset is based on the underlying cause of death of all United States Residents since 1999. Tableau is used to show visualization of the 10 leading causes of death, age-related death rates, and age adjusted death rates for all causes by state. Datasets can be downloaded via csv, json, xls, and xml formats.
